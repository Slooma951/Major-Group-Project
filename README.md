# DVS Note

A multi-functional mobile productivity and mindfulness application designed to help users stay organised, manage tasks, and improve daily productivity.

---

## Overview

DVS Note is a university major group project developed by students at TU Dublin. The application combines productivity tools with personal wellbeing features in a single modern mobile experience.

The system allows users to:

- Create and manage notes
- Organise daily tasks with a to-do list
- Track goals and productivity
- Write journal entries
- Monitor emotions and personal wellbeing
- Manage personal account information

The goal of the project is to provide users with a lightweight and accessible platform that supports both organisation and mindfulness.

## Installation

### Clone the Repository

```bash
git clone https://github.com/Slooma951/Major-Group-Project.git
```

### Navigate into the Project

```bash
cd Major-Group-Project
```

### Install Dependencies

Frontend:

```bash
npm install
```

Backend:

```bash
npm install
```

---

## Running the Project

### Start Frontend

```bash
npm run dev
```

### Start Backend

```bash
npm start
```
